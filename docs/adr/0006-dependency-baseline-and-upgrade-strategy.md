# 依赖版本基线锁定与升级治理策略

作为通用企业级 Starter 套件与基础设施底座，`ateng-boot` 遵循“**LTS 稳态优先、次版本克制演进、补丁版本及时跟进（Patch Up-to-date）**”的依赖治理原则。

1. **Spring Boot 基线**：锁定 `3.3.x` LTS 生命周期支柱（升级至 `3.3.13` 最新稳定补丁版），暂不跨次版本激进升级至 `3.4.x`。这确保了与下游微服务生态（`ateng-cloud` 所依赖的 Spring Cloud 2023.0.x 及 Spring Cloud Alibaba 生态）保持 100% 二进制兼容，规避底层 Bean 注入规则调整与破坏性变更。
2. **MyBatis-Plus 基线**：升级至 `3.5.17`，全面受益于 `mybatis-plus-jsqlparser` 独立分包后的多方言动态解析性能提升与安全防御增强。
3. **准出测试红线**：任何外部依赖版本的升级调整，均以全工程自动化测试套件（含 H2 内存库端到端集成测试）100% 绿色回归作为准出验收标准。
